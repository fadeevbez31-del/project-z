# PROJECT Z — функции игроков

## Порядок установки

1. Сохрани резервную копию Supabase (таблицы, политики RLS, функции).
2. Сначала выполни `forum/admin_migration.sql` из предыдущего этапа.
   Если он ещё выдаёт ошибку — исправь её до перехода к следующему шагу.
3. В Supabase → SQL Editor → New query открой **`forum/community_migration.sql`**,
   скопируй **весь** файл, нажми Run. SQL запускается владельцем проекта.
4. Убедись, что миграция выполнилась без ошибок, и обнови форум Ctrl+F5.
5. Протестируй двумя аккаунтами: обычный игрок и администратор.

## Реализовано

- Аватар: загрузка PNG/JPG/WEBP до 2 МБ в уже используемый
  `forum-attachments` Storage bucket (или HTTPS-ссылка).
  Для загрузки должны существовать действующие Storage policies.
- Баннер профиля: HTTPS-ссылка, описание, ник; XP/уровень.
- XP: 10 за новую тему, 3 за ответ, серверные триггеры; достижения
  за первую тему, первый ответ и 100 XP. Начисление начинается с
  установки миграции; исторические сообщения не пересчитываются.
- Реакции 👍 ❤️ 🔥 💀 (одна на пользователя и тему).
- Уведомления о новых ответах, упоминаниях и личных сообщениях.
- Личные сообщения; просмотр своего почтового ящика, отправка из профиля.
- Упоминания формата `@nickname` латиницей/цифрами/подчёркиваниями
  (от 3 до 40 символов); до пяти разных адресатов за сообщение.
- Избранные темы, редактирование собственных тем и ответов.
- Поиск по заголовкам тем (не полнотекстовый поиск по содержимому).
- Заявки VIP/разбан с SteamID и текстом; админ может одобрить/отклонить.
- Голосование за карты: название латиницей, цифрами, подчёркиванием.
- Рейтинг игроков по XP.

## Безопасность и ограничения

- Все записи в новых таблицах происходят через проверяющую
  `forum_community_action` (SECURITY DEFINER). Таблицы имеют RLS,
  права прямого INSERT/UPDATE/DELETE для anon/authenticated отозваны.
- XP выдаётся только триггерами при реальном создании тем и ответов.
  Нельзя начислять XP через JavaScript.
- Перед запуском обязательно проверь существующие политики
  `profiles`, `forum_topics`, `forum_replies`, `storage.objects`.
  Старые широкие политики могут допускать изменения вне новых RPC.
- Ник, bio, ссылки и содержимое выводятся в DOM через `textContent`,
  а не через небезопасный HTML.
- Для аватарок сейчас используется общий Storage bucket с
  публичными URL. Не загружай туда личные/конфиденциальные файлы.
- Голосование ограничено одним голосом за одну карту от аккаунта;
  пользователь может проголосовать за несколько карт. Каталог
  утверждённых карт и защита от накрутки — отдельный этап.
- Сообщения пока отображаются единым списком, без отдельных диалогов
  и уведомлений в реальном времени.
- Поиск работает по заголовкам; рейтинг и списки ограничены первыми
  50–100 записями.
- Достижения `ten_posts` зарезервировано, но пока не выдаётся.
- Счётчик просмотров не является подсчётом уникальных посетителей.
- SourceBans и заявки на разбан пока не связаны автоматически.
- В базе хранятся сообщения пользователей: нужны правила хранения
  данных и модерации.

## Если SQL выдал ошибку

Пришли точный текст ошибки и номер строки из Supabase. Не запускай
части миграции выборочно: она заключена в `begin; ... commit;`.
